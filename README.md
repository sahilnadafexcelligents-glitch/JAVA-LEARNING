## 🛠️ Prerequisites & Setup

### Requirements
- **Java Development Kit (JDK)**: JDK 17 or JDK 21 recommended.
- **IDE / Text Editor**: VS Code, IntelliJ IDEA, or Eclipse.
- **Build Tool / Framework**: Maven / Gradle (for Spring Boot modules).
- **Database**: MySQL / PostgreSQL (for SQL and Spring Data JPA modules).

### How to Compile & Run Java Code

Navigate to any module directory and run:

```bash
# Compile the Java file
javac ClassName.java

# Execute the compiled class
java ClassName
```
