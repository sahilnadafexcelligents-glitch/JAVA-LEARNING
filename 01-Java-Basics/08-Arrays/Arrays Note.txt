1. WHAT IS AN ARRAY AND WHY IS IT USED?
================================================================================

WHAT?
-----
An array is a container that holds a FIXED number of values of the SAME data 
type in a single variable.

Think of it like a ROW OF LOCKERS in school:
  - Each locker has a number (called INDEX)
  - Each locker holds one item
  - All lockers are the same size (same data type)

WHY USE IT?
-----------
Without arrays, you would write:

    int mark1 = 85;
    int mark2 = 90;
    int mark3 = 78;
    int mark4 = 92;
    // ... imagine 100 students!

With arrays, you write:

    int[] marks = {85, 90, 78, 92};

One variable. Many values. Clean code.


2. SYNTAX (How to Create Arrays)
================================================================================

There are THREE ways to create an array in Java:

WAY 1: Declare + Create + Assign separately
--------------------------------------------
    // Step 1: Declaration
    int[] numbers;

    // Step 2: Creation (memory allocation) - 5 slots
    numbers = new int[5];

    // Step 3: Assignment
    numbers[0] = 10;
    numbers[1] = 20;
    numbers[2] = 30;
    numbers[3] = 40;
    numbers[4] = 50;

WAY 2: All in one line
----------------------
    int[] numbers = new int[5];
    numbers[0] = 10;
    // ... etc

WAY 3: Shortcut (Declare + Initialize together)
-----------------------------------------------
    int[] numbers = {10, 20, 30, 40, 50};

KEY RULES:
----------
  * Index starts at 0 (NOT 1)
  * Last index is always: length - 1
  * Once created, SIZE CANNOT CHANGE


3. SIMPLE EXAMPLES
================================================================================

EXAMPLE 1: Basic Array
----------------------

    public class ArrayDemo {
        public static void main(String[] args) {
            String[] fruits = {"Apple", "Banana", "Mango"};

            System.out.println(fruits[0]);  // Apple
            System.out.println(fruits[1]);  // Banana
            System.out.println(fruits[2]);  // Mango

            // Length of array
            System.out.println("Total fruits: " + fruits.length);  // 3
        }
    }


EXAMPLE 2: Loop through Array (for loop)
----------------------------------------

    public class ArrayLoop {
        public static void main(String[] args) {
            int[] scores = {75, 88, 92, 67, 85};

            for (int i = 0; i < scores.length; i++) {
                System.out.println("Student " + (i+1) + ": " + scores[i]);
            }
        }
    }


EXAMPLE 3: Enhanced for-loop (for-each) - Cleaner!
--------------------------------------------------

    public class ForEachDemo {
        public static void main(String[] args) {
            double[] prices = {99.5, 45.0, 120.75, 30.0};

            for (double price : prices) {
                System.out.println("Price: $" + price);
            }
        }
    }


EXAMPLE 4: Update Array Values
------------------------------

    public class UpdateArray {
        public static void main(String[] args) {
            int[] ages = {20, 25, 30};
            ages[1] = 26;  // Changed 25 to 26

            for (int age : ages) {
                System.out.println(age);
            }
        }
    }


4. REAL-WORLD EXAMPLE
================================================================================

HOSPITAL PATIENT TEMPERATURE TRACKER
------------------------------------

    public class HospitalTracker {
        public static void main(String[] args) {
            // Temperatures of 5 patients (in Celsius)
            double[] temperatures = {98.6, 99.2, 101.5, 97.8, 98.4};

            double total = 0;
            int feverCount = 0;

            for (int i = 0; i < temperatures.length; i++) {
                total += temperatures[i];

                if (temperatures[i] > 100.0) {
                    System.out.println("ALERT: Patient " + (i+1) + " has fever!");
                    feverCount++;
                }
            }

            double average = total / temperatures.length;
            System.out.println("Average temperature: " + average);
            System.out.println("Total fever cases: " + feverCount);
        }
    }

OUTPUT:
-------
    ALERT: Patient 3 has fever!
    Average temperature: 99.1
    Total fever cases: 1


5. COMMON MISTAKES (Don't Do These!)
================================================================================

MISTAKE 1: ArrayIndexOutOfBoundsException
-----------------------------------------
    int[] arr = {10, 20, 30};
    System.out.println(arr[3]);  // ERROR! Valid indexes: 0,1,2 only


MISTAKE 2: Forgetting "new" keyword
-----------------------------------
    int[] arr;          
    arr = {1, 2, 3};   // ERROR! Must use: new int[]{1,2,3} if after declaration


MISTAKE 3: Trying to print array directly
-----------------------------------------
    int[] arr = {1, 2, 3};
    System.out.println(arr);  // Prints garbage like [I@6d06d69c
    // FIX: Use Arrays.toString(arr) or use a loop


MISTAKE 4: Array length vs String length()
------------------------------------------
    int[] arr = {1, 2, 3};
    String name = "Java";

    System.out.println(arr.length);     // property - NO brackets
    System.out.println(name.length());  // method - WITH brackets


MISTAKE 5: Thinking array size can grow
---------------------------------------
    int[] arr = new int[3];
    arr[3] = 10;  // ERROR! Size is fixed at 3. Use ArrayList for dynamic size.


MISTAKE 6: Assigning one array to another (Reference trap)
----------------------------------------------------------
    int[] a = {1, 2, 3};
    int[] b = a;      // b points to SAME memory as a
    b[0] = 100;       
    System.out.println(a[0]);  // 100! a also changed!

7. INTERVIEW QUESTIONS
================================================================================

Q: What is the default value of array elements?
A: 0 for int, 0.0 for double, false for boolean, null for objects

Q: Can we change array size after creation?
A: No. Arrays have fixed size. Use ArrayList for dynamic size.

Q: What is ArrayIndexOutOfBoundsException?
A: Trying to access an index that does not exist (negative or >= length)

Q: Difference between array and ArrayList?
A: Array: fixed size, primitive and objects allowed, faster.
   ArrayList: dynamic size, objects only, slower.

Q: Are arrays passed by value or reference?
A: Reference is passed by value. Method gets a copy of the reference,
   so changes affect the original array.

Q: Time complexity to access an element?
A: O(1) - direct access using index

Q: How to sort an array in Java?
A: Arrays.sort(arr) - uses quicksort/dual-pivot quicksort for primitives

Q: How to search in a sorted array?
A: Arrays.binarySearch(arr, key) - returns index or negative if not found


8. CODING CHALLENGE
================================================================================

CHALLENGE: Find the Missing Number
----------------------------------

PROBLEM:
You are given an array containing n-1 numbers from 1 to n with one number 
missing. Find the missing number.

EXAMPLE:
Input:  {1, 2, 4, 5, 6}
Output: 3 is missing

STARTER CODE:
-------------
    public class MissingNumber {
        public static void main(String[] args) {
            int[] arr = {1, 2, 4, 5, 6};  // n = 6, one number missing

            // Your logic here

            System.out.println("Missing number is: " + missing);
        }
    }

HINT:
-----
Sum of 1 to n = n * (n + 1) / 2
Missing number = Expected Sum - Actual Sum


BONUS: SOLUTION TO CHALLENGE
================================================================================

    public class MissingNumber {
        public static void main(String[] args) {
            int[] arr = {1, 2, 4, 5, 6};
            int n = arr.length + 1;  // Since one is missing

            int expectedSum = n * (n + 1) / 2;
            int actualSum = 0;

            for (int num : arr) {
                actualSum += num;
            }

            int missing = expectedSum - actualSum;
            System.out.println("Missing number is: " + missing);
        }
    }
