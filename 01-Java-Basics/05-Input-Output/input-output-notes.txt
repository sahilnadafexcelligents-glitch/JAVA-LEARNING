Input/Output in Java
====================

1. What is Input/Output (I/O)?
Input means taking data from the user or from a file.
Output means displaying or sending data to the screen or another destination.

In simple words:
- Input = getting information
- Output = showing information

2. Why is I/O used?
I/O is used to:
- read user input
- display results
- show messages
- work with files and external data

3. Basic output in Java
The most common output statement is:
System.out.println();

Example:
System.out.println("Hello Java");

What it does:
- prints text on the screen
- moves to the next line

Other output method:
System.out.print();

Example:
System.out.print("Hello");
System.out.print(" Java");

Difference:
- println() prints and moves to the next line
- print() prints without moving to the next line

4. Basic input in Java
To take input from the keyboard, we use Scanner.

Syntax:
import java.util.Scanner;

Scanner sc = new Scanner(System.in);

Example:
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter your name:");
        String name = sc.nextLine();
        System.out.println("Hello " + name);
    }
}

5. Reading different types of input
A. Read a string
String name = sc.nextLine();

B. Read an integer
int age = sc.nextInt();

C. Read a double
double price = sc.nextDouble();

D. Read a boolean
boolean flag = sc.nextBoolean();

6. Simple examples
Example 1: Print text
System.out.println("Welcome to Java");

Example 2: Print a number
int age = 20;
System.out.println(age);

Example 3: Read name from user
Scanner sc = new Scanner(System.in);
String name = sc.nextLine();
System.out.println("Your name is " + name);

Example 4: Read age from user
Scanner sc = new Scanner(System.in);
int age = sc.nextInt();
System.out.println("Your age is " + age);

7. Real-world example
Imagine a login system.
The program asks the user for their username and password.

Scanner sc = new Scanner(System.in);
System.out.println("Enter username:");
String username = sc.nextLine();

System.out.println("Enter password:");
String password = sc.nextLine();

System.out.println("Welcome " + username);

Here, input is used to get user data, and output is used to show a message.

8. Important concept: String concatenation
You can combine text and variables using +.

Example:
String name = "Asha";
int age = 21;
System.out.println("My name is " + name + " and I am " + age);

9. Common mistakes
- Forgetting to import Scanner
import java.util.Scanner;

- Using nextInt() before nextLine()
This can cause input issues.

- Mixing print and println incorrectly
System.out.print("Hello");
System.out.println(" World");

- Not closing the scanner
sc.close();
